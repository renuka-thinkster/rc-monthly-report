⑤ Target — by Site

Set monthly Target & Working Days per site. Pick the As-of date to see cumulative progress up to that day.
Achieved = sum of Daily Sales entries on/before the As-of date (in the selected month). Events falls back to the monthly Sales sub-total.
Day Target = Target ÷ Working Days · Per Day Sales = Achieved ÷ Days Entered · % Achieved = Achieved × 100 ÷ Target · % Day Target = Achieved × 100 ÷ (Day Target × Days Entered) — i.e., on-pace measure (100% = exactly on track).

Track each product's consumption per month. Consumed = Opening + Received − Closing. Value = Consumed × Rate ₹/unit.
Click + Add Product to add a new item. Existing products can be renamed or removed (delete clears all months for that product). Lock state follows the same per-month Save/Edit rule as other tabs.
